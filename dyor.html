Verified · offline only · Nov 16, 2026

iancoleman.io — BIP39 Mnemonic Code Converter

The gold-standard BIP39 reference, already one of our sources: client-side, open-source (MIT), repo since 2014 (~4.2k stars), converts mnemonics to seeds, BIP32 root keys and derived addresses across BIP32/44/49/84/141. Coinomi's official docs recommend it for key recovery. The rule stands: real seeds go in OFFLINE only — download bip39-standalone.html from the GitHub releases, go airplane mode, then open it. Never paste a seed into the live site, and never use iancoleman.net — a third-party lookalike, not official.

Sources: iancoleman.io/bip39 ↗ GitHub ↗ Offline release ↗

Verified · caution · Nov 16, 2026

brainwalletx.github.io — Brainwallet tool

A legit fork of the classic brainwallet.org tool (the community moved here after security flaws were found in the original) — client-side JS that turns a passphrase into a BTC key via plain SHA-256, plus a tx builder and sign/verify-message tools. Source: github.com/brainwalletX/brainwalletX.github.io (MIT). Safe uses only: verifying signed messages (public data) and recovering an old legacy brainwallet, offline, from the downloaded source. Brainwallets as storage are broken — no key-stretching, so any human passphrase is brute-forceable and bots sweep them (DEFCON 23). Never fund one, never paste a funded key into the live site.

Sources: brainwalletx.github.io ↗ GitHub ↗ bitcointalk ↗

Verified · avoid · Nov 16, 2026

privatekeys.pw — "Private Keys Database"

A directory that generates "every" BTC/ETH private key on the fly from the page number (2^256 keys — mathematically you will never find a funded one by browsing), with balance checks, a brainwallet collection, and a mnemonic converter. Trust checkers disagree wildly (ScamMinder 10/100, Scam Detector 40.4/100, EvenInsight 90/100) and there is no team or repo to hold accountable. The danger is structural: its key search and mnemonic converter invite you to paste a private key or seed into a live third-party site. Never paste real key material into it — or any site like it. Nothing here that we need.

Sources: privatekeys.pw ↗ ScamMinder ↗ Scam Detector ↗

Verified · skip · Nov 16, 2026

But its core flow is pasting your seed into a live web page — which breaks our rule — the repo (40 commits, 29 stars, front-end only) looked abandoned to bitcointalk users in mid-2025, an Oct 2025 "GitHub update" claim comes only from a syndicated PR blast, and phishing clones exist. We already have better tooling (VM keystore + DECO Wallet app), so: skip.
