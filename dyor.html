Chainlink LINK faucet

The official testnet LINK faucet. 25 test LINK per request plus native gas tokens — up to 0.5 Sepolia ETH, the biggest Sepolia drip available. Around 60 testnets listed, including Sepolia, Base Sepolia, Arbitrum Sepolia, OP Sepolia, Hoodi and Arc. Sepolia LINK token: 0x779877A7B0D9E8603169DdbD7836e478b4624789.

Verified · Nov 16, 2026

Relay

Relay is a legit intent-based cross-chain bridge and swap protocol by Reservoir — $20B+ settled, 85+ chains, powering Phantom and MetaMask. But testnet support is narrow: only Sepolia and Base Sepolia, verified live from their API. Their own docs say testnets are not recommended for swaps (no DEX liquidity) — bridging only. The mainnet quote API has required an API key since October 2, 2026. Beware a different "Relay Protocol" in the Synergy Network ecosystem — not the same thing — and old airdrop posts from the Goerli/Mumbai era are stale.

Sources: relay.link ↗ testnet.relay.link ↗ Relay docs ↗

The testnet staking portal is real and the testnet is live (SVM, RPC answering), with a working faucet.
