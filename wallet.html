{the build}

How it was built

Seven steps, all in generate.js — run once, refuses to overwrite an existing wallet, prints only public addresses and test results. Never a seed, never a private key, never the passphrase.

  1. Seed — 12-word BIP39 mnemonic, 128-bit entropy.
  2. Derive — five chains from the one seed, standard paths (table below).
  3. Machine keystore — keys encrypted AES-256-GCM with a random key in ~/.config/multichain-wallet/vm-key (0600), so the agent can sign without asking each time.
  4. Encrypted backup — seed + every private key, scrypt (N=16384) + AES-256-GCM with your own backup passphrase. Without it, unreadable.
  5. EVM keystore V3 — same passphrase, imports into MetaMask desktop.
  6. Addresses file — public addresses only, safe to share.
  7. 8 tests — EVM + Solana sign/verify, TRON + BTC re-derive, backup + keystore decrypt round-trips, EVM keystore V3 round-trip. All PASS before the wallet touched a faucet.

{decryptor}

Decryptor tools

Two offline ways to open the encrypted backup. Both run locally — no network code, nothing leaves your device.

Browser decryptor

One HTML file, pure-JS scrypt + WebCrypto AES-GCM. Pick the backup file, enter your password, get the seed + keys with copy buttons. Works on a phone.

Open it →

Node decryptor

decrypt.js — no dependencies. --verify checks the password and shows addresses only; without it, the full backup.

decrypt.js ↗

Stay safe: the decryptor shows your seed phrase and private keys — never paste them anywhere, never screenshot them. For maximum safety, download the decryptor from the repo and open it with Wi-Fi off.
